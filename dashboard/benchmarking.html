Benchmarking with FSEVAL

The FSEVAL library allows you to reproducibly benchmark feature selection methods on high-dimensional datasets, analyze their runtime scalability, and compute the stability of their performance curves. The results it produces can be loaded directly into this dashboard.

Installation

Install the package directly from PyPI. The dashboard reads the result files of version 1.3.0 or later.

Install via pip
pip install -U sdufseval

Full Benchmark, Stability, and Runtime Example

This script executes a complete evaluation pipeline:

  • Performance evaluation using supervised, unsupervised, model-agnostic, and custom metrics
  • Custom local neighborhood consistency evaluation using Shared Nearest Neighbors
  • Stability analysis of every performance curve
  • Runtime scalability experiments
benchmark.py
from sdufseval import FSEVAL import numpy as np from sklearn.neighbors import NearestNeighbors def snn_consistency_k5(X_orig, X_sub, y): """ Calculates the average proportion of shared nearest neighbors (k=5) between the original space and the feature-selected subspace. """ k = min(5, X_orig.shape[0] - 1) def get_nn_indices(data, n_neighbors): nbrs = NearestNeighbors(n_neighbors=n_neighbors + 1).fit(data) _, indices = nbrs.kneighbors(data) return indices[:, 1:] nn_orig = get_nn_indices(X_orig, k) nn_sub = get_nn_indices(X_sub, k) intersections = [ len(np.intersect1d(nn_orig[i], nn_sub[i])) for i in range(len(nn_orig)) ] return np.mean(intersections) / k if __name__ == "__main__": # required, FSEVAL runs in parallel processes DATASETS_TO_RUN = ['colon', 'leukemia', 'prostate_GE'] evaluator = FSEVAL( output_dir="benchmark_results", data_dir="datasets", avg_steps=5, random_state=0, n_jobs=-1, eval_type=["supervised", "unsupervised", "model_agnostic", "custom"], custom_metrics={"SNN_K5": snn_consistency_k5}, save_classifier_results=True, # per-classifier ACC/AUC, used by the dashboard ) methods_list = [ { 'name': 'Random', 'type': 'unsupervised', 'stochastic': True, 'func': evaluator.random_baseline }, { 'name': 'Variance_Baseline', 'type': 'unsupervised', 'stochastic': False, 'func': lambda X: np.var(X, axis=0) } ] print(">>> Starting Integrated Evaluation (Global & Local metrics)...") evaluator.run(DATASETS_TO_RUN, methods_list) print("\n>>> Starting Scalability Analysis...") evaluator.timer( methods=methods_list, vary_param='both', time_limit=3600 )

Resumable runs: running the script again skips every (dataset, method) pair that is already complete, so an interrupted benchmark can simply be restarted. Pairs whose settings changed are recomputed automatically; use evaluator.run(..., force=True) to recompute everything.

Your own methods: each method is a dictionary with a name, a type ("unsupervised" receives X, "supervised" receives X, y), a func that returns one score per feature (higher means more important), and optionally stochastic and params.

Output

All result files are written to benchmark_results/. Each file has one row per dataset and one column per feature subset size. The last part of every name records the settings the values depend on, for example SI5_CV5_RS0 (5 classifier runs, 5-fold cross-validation, random state 0) or USI10_RS0 (10 clustering runs).

FileContent
{Method}_{Metric}_{Range}_{Settings}.csvCLSACC, NMI and AAD per subset size, and ACC/AUC averaged over the classifiers.
{Method}_{Classifier}_{Metric}_{Range}_{Settings}.csvACC and AUC of each classifier (with save_classifier_results=True).
{Method}_{Metric}_Stability_{Range}_{Settings}.csvStability of each performance curve.
time_analysis_features.csv, time_analysis_instances.csvRuntimes from the scalability analysis.

To explore your results, upload these files to the dashboard with the Import button, or place them in the resources/ folder when running the dashboard locally. The dashboard shows ACC and AUC per classifier, so run FSEVAL with save_classifier_results=True. Custom metrics such as SNN_K5 are saved as well, but the dashboard displays only CLSACC, NMI, ACC, AUC, and AAD.
