Benchmarking with FSEVAL

The FSEVAL library allows you to reproducibly benchmark feature selection methods on high-dimensional datasets, analyze their runtime scalability, and compute selection stability.

Installation

Install the package directly from PyPI:

Install via pip
pip install sdufseval

Full Benchmark, Stability, and Runtime Example

This script executes a complete evaluation pipeline:

  • Performance evaluation using supervised, unsupervised, model-agnostic, and custom metrics
  • Custom local neighborhood consistency evaluation using Shared Nearest Neighbors
  • Runtime scalability experiments
benchmark.py
from sdufseval import FSEVAL import numpy as np from sklearn.neighbors import NearestNeighbors def snn_consistency_k5(X_orig, X_sub, y): """ Calculates the average proportion of shared nearest neighbors (k=5) between the original space and the feature-selected subspace. """ k = 5 k = min(k, X_orig.shape[0] - 1) def get_nn_indices(data, n_neighbors): nbrs = NearestNeighbors(n_neighbors=n_neighbors + 1, algorithm='auto').fit(data) _, indices = nbrs.kneighbors(data) return indices[:, 1:] nn_orig = get_nn_indices(X_orig, k) nn_sub = get_nn_indices(X_sub, k) intersections = [ len(np.intersect1d(nn_orig[i], nn_sub[i])) for i in range(len(nn_orig)) ] return np.mean(intersections) / k if __name__ == "__main__": DATASETS_TO_RUN = ['colon', 'leukemia', 'prostate_GE'] evaluator = FSEVAL( output_dir="benchmark_results", avg_steps=5, eval_type=["supervised", "unsupervised", "model_agnostic", "custom"], custom_metrics={"SNN_K5": snn_consistency_k5} ) methods_list = [ { 'name': 'Random', 'type': 'unsupervised', 'stochastic': True, 'func': evaluator.random_baseline }, { 'name': 'Variance_Baseline', 'type': 'unsupervised', 'stochastic': False, 'func': lambda X: np.var(X, axis=0) } ] print(">>> Starting Integrated Evaluation (Global & Local metrics)...") evaluator.run(DATASETS_TO_RUN, methods_list) print("\n>>> Starting Scalability Analysis...") evaluator.timer( methods=methods_list, vary_param='both', time_limit=3600 )

Output

After running the script, the following files are generated for the dashboard:

  • benchmark_results/ folder containing benchmark performance metrics.
  • Custom metric results including SNN_K5.
  • Runtime scalability CSV files generated by the timer analysis.
