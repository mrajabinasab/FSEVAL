Dashboard Documentation

This dashboard provides a comprehensive interface for evaluating feature selection algorithms. It visualizes performance trends, statistical rankings, computational scalability, and the stability of performance curves, based on results produced by FSEVAL.

Main Controls

  • Dataset: Selects the dataset shown in the performance curves and the stability chart.
  • Metric: CLSACC (clustering accuracy), NMI (normalized mutual information), ACC (classification accuracy), AUC (area under the ROC curve), or AAD (model-agnostic, lower is better).
  • Classifier: Selects the classifier for ACC and AUC: Random Forest (default), SVM, KNN, XGBoost, or Decision Tree. It is active only when ACC or AUC is selected, since the other metrics do not use a classifier.
  • Range: Toggles between 10Percent (0.5% to 10% of the features, in steps of 0.5%) and 100Percent (5% to 100%, in steps of 5%).
  • Import: Uploads your own FSEVAL result files. They are added to the benchmark for your session only.
  • Exclude: Hides datasets or methods from all views, written as Python lists: 
    DATASETS = ['colon', 'leukemia']
METHODS = ['Random']

Core Features

Performance Curves The selected metric as a function of the percentage of selected features. For the Random baseline, a shaded band shows one standard deviation over its repetitions when the results contain every repetition.
Stability Analysis A bar chart of the stability of each method's performance curve on the selected dataset, computed by FSEVAL with FSDEM. FSEVAL computes it for the classifier average only, so it is not available when a classifier is selected for ACC or AUC.
Statistical Ranking Critical Difference (CD) diagrams over all datasets, in a standard version based on average ranks and in the MARS version based on weighted ranks. Methods joined by a bar are not significantly different.
Computational Scalability Runtime as a function of the number of features or instances, on a logarithmic scale. Runs that exceeded the time limit are not plotted.

Data Naming Conventions

The dashboard reads the result files written by FSEVAL 1.3.0 or later and identifies them by name. The {Settings} part records the evaluation settings, for example SI5_CV5_RS0 for ACC and AUC, USI10_RS0 for CLSACC and NMI, and RS0 for AAD.

Performance Data

{Method}_{Metric}_{Range}_{Settings}.csv for CLSACC, NMI, and AAD

Example: VCSDFS_AAD_10Percent_RS0.csv

Per-Classifier Performance Data

{Method}_{Classifier}_{Metric}_{Range}_{Settings}.csv for ACC and AUC

Example: VCSDFS_RANDOMFOREST_ACC_100Percent_SI5_CV5_RS0.csv

The classifier is one of RANDOMFOREST, SVM, KNN, XGBOOST, or DECISIONTREE. FSEVAL writes these files when run with save_classifier_results=True. ACC and AUC files without a classifier (the average over classifiers) are not used by the dashboard.

Stability Data

{Method}_{Metric}_Stability_{Range}_{Settings}.csv

Example: VCSDFS_NMI_Stability_100Percent_USI10_RS0.csv

Runtime Data

time_analysis_features.csv and time_analysis_instances.csv

Columns Required: Performance files must have a Dataset column and numeric percentage columns (e.g., '0.05'). Stability files must have Dataset and Stability columns. Runtime files must have a Method column followed by one column per data size. If several files differ only in their settings, the most recent one is used.

Detailed Score Table

The score table summarizes the curves: each cell is the mean of a method's scores over all subset sizes of the selected range, which reflects the area under its performance curve. In each dataset column, the best score is shown in bold and the second best is underlined; for AAD, lower scores are better. The same per-dataset means are used to rank the methods in the CD diagrams.

Publication Tools

The performance curves, stability chart, both CD diagrams, and runtime plot can be exported directly to PDF for inclusion in research papers. The score table can be exported as a LaTeX table, with the best and second-best results marked.
